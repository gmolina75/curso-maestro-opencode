# Clase 41: Migración desde Otros Agentes

## Resumen Ejecutivo

Esta clase cubre migración desde otros agentes. CLAUDE.md → AGENTS.md (mismo propósito, formato similar) No hay modo plan nativo en Claude Code; usar Plan mode de OpenCode Slash commands similares: /clear, /compact, /help.

A lo largo de la sesión se exploran los siguientes temas: mapeo de funcionalidades, de claude code a opencode, de cursor a opencode, tips de transición. Al finalizar, el estudiante tendrá una base práctica para aplicar estos conceptos en sus propios proyectos con OpenCode.

## Objetivos de Aprendizaje

- CLAUDE.md → AGENTS.md (mismo propósito, formato similar)

- Slash commands similares: /clear, /compact, /help

### De Cursor a OpenCode

- .cursorrules → AGENTS.md + skills
- Composer (Agent) → Build mode con Plan previo
- Chat mode → Plan mode (solo lectura)
- @ symbols similares para referenciar archivos
- OpenCode es open source y multi-proveedor

### Tips de Transición

- Empezar con Plan mode para familiarizarse sin riesgo
- Configurar proveedor favorito primero
- Crear AGENTS.md con las reglas que tenías antes
- Exportar conversaciones antiguas para referencia
- Practicar atajos: Ctrl+X leader, Tab para cambiar modo
