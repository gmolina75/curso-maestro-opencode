# Design Document - Curso OpenCode

## Style Overview
Clean, professional, technical education style. White/light backgrounds with dark text and blue accents. Minimalist, consistent with existing course presentations.

## Color Palette
- Primary: #2563EB (blue)
- Secondary: #1E293B (dark slate)
- Accent: #10B981 (green for checkmarks/success)
- Background: #FFFFFF
- Text: #1F2937
- Light Gray: #F3F4F6 (for code blocks/cards)
- Border: #E5E7EB

## Typography
- Title: MiSans, 36px, bold, $secondary
- Subtitle: MiSans, 20px, $text
- Body: MiSans, 18px, $text, lineHeight 1.6
- Code: MiSans, 16px, monospace feel, #374151
- Bullet: MiSans, 18px, $text

## Layout
- Page size: 1280x720 (16:9)
- Margins: 80px left/right, 60px top/bottom
- Title area: top section, 80px height
- Content area: middle, flexible
- Footer: subtle line or nothing

## Element Styles
- Code blocks: rounded rect, fill $lightGray, padding
- Bullet lists: standard unordered lists
- Checkmarks: green accent for summary slides
- Demo slides: highlighted with accent color
