# Clase 36: Desktop App

## Resumen Ejecutivo

Esta clase cubre desktop app. Aplicación de escritorio nativa (beta) Interfaz gráfica sin necesidad de terminal Funcionalidad equivalente a la TUI.

A lo largo de la sesión se exploran los siguientes temas: ¿qué es la desktop app?, instalación, diferencias con tui, cuándo usar desktop vs tui. Al finalizar, el estudiante tendrá una base práctica para aplicar estos conceptos en sus propios proyectos con OpenCode.

## Objetivos de Aprendizaje

- Aplicación de escritorio nativa (beta)
- Interfaz gráfica sin necesidad de terminal
- Funcionalidad equivalente a la TUI
- Soporta drag-and-drop de archivos e imágenes
- Notificaciones de escritorio integradas

### ¿Qué es la Desktop App?

- Aplicación de escritorio nativa (beta)

### Instalación

```bash
# macOS
brew install --cask opencode

# Windows (próximamente)
# Descargar desde opencode.ai/download

# Linux (AppImage)
wget opencode.ai/download/linux -O opencode.AppImage
```

- Requiere tener instalado el CLI previamente
- Comparte configuración con TUI
- Actualizaciones automáticas vía autoupdate

### Diferencias con TUI

Contenido visual de la presentación (ver diapositiva `36-diferencias`).

### Cuándo usar Desktop vs TUI

- **Desktop:** Usuarios que prefieren GUI, designers, managers
- **TUI:** Developers hardcore, servidores remotos, SSH
- **Desktop:** Trabajo visual con muchas imágenes
- **TUI:** Entornos con recursos limitados
- **Desktop:** Integración con otros apps de escritorio
